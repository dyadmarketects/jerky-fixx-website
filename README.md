# Jerky Fixx Website (Version 2 mockup)

Scroll-driven 3D website mockup for **Jerky Fixx**, Albuquerque's small batch carne seca dealer. Built by DYAD Marketects.

## Live site

https://jerkyfixx.com (GitHub Pages, custom domain via Cloudflare DNS)

## What's here

| Path | Contents |
| --- | --- |
| `index.html` | Home page markup and its 3D/scroll module script |
| `cart.html` | Cart and checkout page, and the **source of the shared header, menu, tab bar, cookie banner and footer** |
| `jerky/`, `our-story/`, `the-lab/`, `dealer-locator/`, `vip-club/`, `contact/`, `faq/` | Dedicated pages, generated by `tools/build_pages.py` |
| `privacy.html`, `terms.html`, `cookies.html`, `accessibility.html`, `404.html` | Legal pages and 404, generated by `tools/build_pages.py` |
| `tools/pages/` | Sources for every generated page above (edit these, not the output) |
| `blog/` | The Fixx Blog, generated by `tools/build_blog.py` (see `blog/README.md`) |
| `css/site.css` | Site styles; `legal.css` adds the interior page styles, `blog.css` the blog |
| `js/shop.js` | Shared shop code: flavors, cart, forms, cookie consent, mobile menu, `FORM_ENDPOINT` |
| `js/sections.js` | Shared section code: flavor menu and detail, order form, VIP and alert forms, lab chapters, slideshow, calendar file |
| `models/` | 13 web-optimized 3D models (`.glb`, meshopt compressed, about 9 MB total) |
| `img/` | Logo, icons, backgrounds and photos (WebP) |
| `fonts/` | Zuume Rough, Fibre and Macabro, subset to WOFF2 |
| `vid/` | "In the Lab" clip and poster |

Libraries load from CDNs, so there's no build step: Three.js 0.169 (jsDelivr), GSAP 3.12.5 + ScrollTrigger (cdnjs) and Lenis 1.1.13 (jsDelivr).

## Run it locally

The models load with `fetch`, so open the site through a local server rather than double-clicking the file:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Rebuild the generated pages

Python 3 only, nothing to install. Run from the repo root after editing `tools/pages/*.html`, the nav or footer in `cart.html`, a section of `index.html` that an interior page reuses, or the `FLAVORS` list:

```bash
python3 tools/build_pages.py   # interior, legal and 404 pages, home structured data, sitemap (non-blog entries)
python3 tools/build_blog.py    # blog pages, feed, blog sitemap entries, home "latest posts"
```

Both are idempotent and end with a validation report (titles, descriptions, one h1, canonicals, links, JSON-LD); they exit non-zero if anything fails. Never edit the generated HTML by hand.

How the pieces fit:

- **Navigation and footer** live in `cart.html`. The builders copy them everywhere (and into `index.html`).
- **Interior pages reuse the home sections**: `{{section:menu}}` in `tools/pages/jerky.html` pulls `<section id="menu">` out of `index.html`, so the menu grid, dealer map, forms, lab video and FAQ have one source.
- **Structured data**: Organization, WebSite and LocalBusiness on the home page; BreadcrumbList on every interior page; Product/Offer (names and prices from `js/shop.js`, no ratings) on `/jerky/`; FAQPage on `/faq/` only.
- The home page keeps every section and its anchors (`/#menu`, `/#dealer` ...). A deep link scrolls to its section once the intro finishes.

## Forms and orders

All forms (cart checkout, contact order or question, VIP, dealer alerts) post to a Google Apps Script web app that emails jerkyfixx@gmail.com and dyadmarketects@gmail.com and logs every submission in a shared Google Sheet. Setup: `backend/SETUP.md`, then paste the web app URL into `FORM_ENDPOINT` at the top of `js/shop.js`. Until then, forms open a pre-filled email to both addresses.

Order forms (cart checkout, and the contact form when "Place an order" is picked) require a delivery address: street, optional apt or gate code, city, state and ZIP. It lands in the **Address** column of the Sheet and in the "Deliver to" line of both emails, and the customer confirmation tells them the dealer will text a photo once the package is dropped off. If you already deployed the backend before this change, paste the new `backend/Code.gs` and deploy a new version (Deploy, Manage deployments, Edit, New version).

## Updating content (safe edits)

- Flavors, descriptions, heat levels: `FLAVORS` array in `js/shop.js`
- Top sellers: `TOPN` (names) and `TOPM` (3D ingredients) arrays
- Next event: the `#dealer` section markup in `index.html` and the `icsBtn` calendar code in `js/sections.js`, then rebuild (the dealer locator page reuses it)
- FAQ: the `#faq` section in `index.html` (home and `/faq/`), plus the extra questions in `tools/pages/faq.html`, then rebuild
