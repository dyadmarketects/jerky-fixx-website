## 5. Proposals (ranked)

None of the weekly triggers fired, because they all need Search Console numbers and there was no technical failure. Following the "never rewrite pages without a trigger" rule and the fact that round 1 is only five days old, **no on-site files are changed in this PR.** These are queued for when data supports them:

1. **Get Search Console data into the next run** (highest impact on this process). Without it the CTR, striking distance and unowned query triggers can't work. Expected impact: makes every later proposal evidence based.
2. **Watch overlap on carne seca.** `/blog/new-mexico-jerky-green-chile-carne-seca/` ("New Mexico Jerky and Green Chile Carne Seca") touches three owned intents (/jerky/ NM terms, /green-chile-jerky/, /blog/what-is-carne-seca/) and has no in-content link to the carne seca owner. If Search Console shows it collecting `carne seca` or `new mexico jerky` impressions instead of the owners, add one contextual link to /blog/what-is-carne-seca/ and sharpen its angle. Expected impact: cleaner ownership for carne seca queries.
3. **Assign an owner for `hot cheeto jerky`.** Two pages fit it: /blog/hot-cheeto-jerky/ and /jerky/hot-cheetos/. They already link to each other. Once data shows which one Google prefers, record that page as the owner in the keyword map and keep the other pointing to it. Expected impact: avoids splitting the one query where Jerky Fixx has a unique product angle.
4. **Same check for `green chile jerky`**: /green-chile-jerky/ (owner) vs /blog/green-chile-jerky-ranked-by-heat/. Cross-links are already in place both ways; only act if the blog post outranks the owner.
